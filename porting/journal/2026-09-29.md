# 2026-09-29

## `faust`: `Control` becomes `Param`, `Dsp::controls`/`Dsp::control` become `Dsp::params`/`Dsp::param`

Commit date: 2026-09-29

Source commit: this commit

Requested by the user: the facade now names a UI entry a parameter, as the
`MapUI` methods it mirrors (`setParamValue`, `getParamValue`) do. Renamed
without aliases, like the `dsp.h` renames of 2026-09-27:

- `Control` → `Param`, `ControlKind` → `ParamKind`;
- `Dsp::controls` → `Dsp::params`, `Dsp::control` → `Dsp::param`;
- `ErrorKind::UnknownControl` → `UnknownParam`,
  `ErrorKind::ReadOnlyControl` → `ReadOnlyParam`;
- `crates/faust/src/controls.rs` → `params.rs`, and its private
  `ControlMap` → `ParamMap`.

The docs follow (the crate page, `docs/embedding-layers-{en,fr}.md` with its
file map and Rust example, DIFF-API-008), and so does the public-API
baseline. `ffi_common::ControlRange` and `RawInstance::control_ranges`, which
belong to the FFI crates, keep their names. No behaviour change.

Tests: `crates/faust/tests/{api,ddsp}.rs`, renamed accordingly.
