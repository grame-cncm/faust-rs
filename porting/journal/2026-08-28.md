# 2026-08-28

## Plan: move table index clamping to the signal level, add -ct

Commit date: 2026-08-28

Source commit: this commit

Investigation started from `--dump-sig-dag` on
`faustlibraries/tests/lean/table_unclamped.dsp`
(`rdtable(16, 1.0, int(hslider(...)))`): the dump shows a raw
`SIGRDTBL(tbl, idx)` while the generated C++ contains
`std::min<int>(..., 15)`. The clamp is invented late, during signal→FIR
lowering (`table_index_with_bounds`, `signal_fir/module/tables.rs:549`,
plus its vector twin), so it is invisible to every signal-level consumer
and cannot be disabled. The C++ reference compiler instead rewrites the
signal itself: `signalTablePromote` in `simplifyToNormalForm`
(`normalform.cpp:115`), i.e. `SignalTablePromotion::safeSigRDTbl/WRTbl`
(`sigPromotion.cpp:577-640`), gated by `-ct` (default 1).

Comparing outputs on the motivating file surfaced three real divergences
beyond the layering: faust-rs emits a minimal interval-driven clamp
(`min` only when the index is provably non-negative) where reference
faust 2.87.10 emits the full `std::max<int>(0, std::min<int>(..., 15))`
pair (C++'s interval-based min/max pruning is disabled as buggy,
`maxprim.hh:95`); faust-rs falls back to modular wrapping when the index
interval is unknown where C++ clamps; and the `wrtbl` write index is
always wrapped with no interval refinement at all.

Wrote `porting/table-clamp-signal-promotion-plan-2026-08-28-en.md`. Core
design: port `SignalTablePromotion` as `normalize::table_promote`, run it
as a new staging step after simplify #2 in `signal_prepare` (fresh retype
before it, C++ ordering so table sizes are constants), thread a
`check_table` option from a new CLI `-ct <0|1>` /`--check-table` through
`Compiler` → `SignalLoweringContext` → `SignalFirOptions` → new
`PrepareOptions`, and retire the FIR-level strategy down to a
`debug_assert!`. Decisions recommended in the plan: full clamp (strict
C++ byte parity), clamp instead of wrap for unknown intervals (semantic
change for out-of-range indexes that aligns with reference Faust), and a
new `--dump-sig-dag-prepared` flag so the clamp is finally visible in a
signal dump. Four gates: G1 pass + unit tests, G2 staging wiring + golden
regeneration + impulse comparison, G3 `-ct` end-to-end, G4 dump + docs.
