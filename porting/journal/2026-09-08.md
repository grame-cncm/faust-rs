# 2026-09-08

## Cranelift 0.117 to 0.135: the JIT emits islands inside blocks

Commit date: 2026-09-08

Source commit: this commit

The five Cranelift crates of `crates/codegen` (`codegen`, `frontend`, `jit`,
`module`, `native`) go from 0.117.2 (wasmtime 30, early 2025) to 0.135.1
(wasmtime 48, the latest stable; 0.136 is a release candidate). The API
changes met by the backend:

- `MemFlags` is now a handle into the function's deduplicated set of flag
  data; `load` and `store` take `impl Into<MemFlagsData>`, so the 24 sites
  pass `MemFlagsData::new()` where they passed `MemFlags::new()`.
- `global_value` is gone; the address of a data object is `symbol_value`.
- `FunctionBuilder::declare_var(ty)` allocates the `Variable` itself: the
  hand-rolled `next_var` counter is gone.
- Branch arguments are `BlockArg`s: the six `jump(header, &[v])` of the loops
  pass `BlockArg::Value(v)`.
- `FunctionBuilder::finalize` takes the target's frontend config,
  `jit.target_config()`.
- `iadd_imm` and `icmp_imm` are deprecated in favour of the explicit
  sign-extending `_s` forms, which are what the old ones did.

No change in the FIR lowering itself, and no warning left (`cargo clippy -p
codegen -p cranelift-ffi`). The lock file also moves the wasmtime internal
crates from 30.0.2 to 48.0.1 and picks up `hashbrown` 0.17, `foldhash` 0.2,
`memmap2` 0.9.11, `libm` 0.2.16.

The lowering-side workaround of the previous entry (`split_long_block`,
2048 CLIF instructions per straight-line block) is not kept: the reason it
existed, islands emitted only between basic blocks, is fixed since
wasmtime#13392 (cranelift 0.133). Checked by disabling the split before
dropping it: the 22 500-term program and the 44 000-statement oscillator-sync
demonstrator, 1.17 MB in one basic block, compile and give the same samples
with and without it.

Gates: `codegen` 369/369, `cranelift-ffi` all suites, the Cranelift impulse
lane 94/94 against the C++ references; the oscillator-sync check
(`faust-hasy/check.py`, eight cases against a numerical Fourier analysis)
unchanged to the last digit.
