## Add the scalar Cmajor emitter core

Commit date: 2026-08-04

Source commit: this commit

Replaced the Cmajor scaffold with a typed FIR-to-Cmajor source emitter. The
first slice emits scalar streams, processor fields, single/double-aware types
and literals, scalar expressions and control flow, delay-array access, math
mapping, helper functions, separated `control`, and the forever-running
one-sample `main` loop. Unsupported FIR types and nodes return stable
`FRS-CGEN-CMAJ-0001..0005` errors rather than assertions or partial source.

The generated lifecycle is intentionally adapted from the upstream Cmajor
exception: `init` calls `classInit` before `instanceInit`, while direct
`instanceInit` calls only `instanceConstants`,
`instanceResetUserInterface`, and `instanceClear`. Module and public API
Rustdoc record the pinned C++ sources, semantic invariants, supported subset,
and compatibility status. The codegen README now classifies Cmajor as scalar
bring-up instead of a scaffold.

Validation: Cmajor codegen unit tests; production signal-to-FIR integration
tests for one-sample I/O, recurrence, fixed delay, lifecycle, and typed
soundfile rejection; complete `codegen` library tests; focused clippy with
warnings denied; `RUSTDOCFLAGS=-Dwarnings cargo doc -p codegen --no-deps`.

## Plan the scalar Cmajor backend port

Commit date: 2026-08-04

Source commit: this commit

Added the Cmajor backend port and test plan against the pinned C++ Faust
reference `8eebea429`. The plan inventories the source container, instruction
visitor, UI/event contract, table specialization, architecture wrappers,
application tooling, and upstream impulse path. It freezes scalar
`-lang cmajor` with single/double precision as the first completion target and
defers polyphonic, `cmajor-dsp`, hybrid, and SDK tooling to separately gated
milestones.

The lifecycle mapping is explicitly `adapted`: Cmajor tables remain processor
instance fields, while generated `init` follows the repository contract
`classInit -> instanceInit` and direct `instanceInit` does not call
`classInit`. The test plan layers pure Rust structural and numeric checks,
pinned C++ differential output, current Cmajor frontend validation, generated
C++ impulse execution, and `-O0`/`-O4` parity.

Validation: C++ Faust 2.84.3 generated scalar noise, UI, table, and double
fixtures at `8eebea429`; Cmajor 1.0.3175 accepted all four with
`generate --target=syntaxtree`; Markdown whitespace and diff check. The pinned
custom branch asserts in `backendDelayType` for the deferred `cmajor-poly`
probe, which is recorded as a C7 rebaseline/repair requirement.
