Repeated UI display addresses are now accepted like C++ Faust and share a short
name; uniqueness remains enforced on the actual zone-derived endpoints.

## Add the parallel-safe Cmajor impulse harness

Commit date: 2026-08-04

Source commit: this commit

Added `tests/impulse-tests/Make.cmajor`, which sends faust-rs scalar-double
Cmajor output through `cmaj generate --target=cpp`, the pinned C++
`cmajor_cpp_dsp` adapter, and the upstream impulse runner before comparing each
trace with the canonical C++ reference. Unlike upstream's shared scratch names,
each DSP owns a private build directory, and a two-case `make -j2` smoke run
proved the rules do not collide. `control.dsp` is excluded explicitly for the
same reason as in the pinned C++ lane.

The first Cmajor frontend run exposed a target-language mismatch in the emitter:
Faust FIR comparisons have `int32` result type, while Cmajor comparisons produce
`bool` and reject implicit stores to integers. Comparison expressions are now
wrapped in `int32(...)` when required by canonical FIR, with a structural unit
test. The `constant` and `delays` impulse traces then matched their references
both sequentially and in parallel. The upstream adapter prints lifecycle
`checkDefaults` warnings for `delays` because its reset methods are no-ops; this
does not change the matching trace and does not supersede the backend's direct
lifecycle conformance tests.

Validation: codegen Cmajor unit tests; release compiler build; sequential and
parallel two-DSP Cmajor impulse smoke tests with Cmajor 1.0.3175; formatting;
workspace clippy with warnings denied; all workspace/all-target tests; Rust
golden check; and release compile-budget check without baseline changes.

## Validate concrete Cmajor table lowering

Commit date: 2026-08-04

Source commit: this commit

Resolved the C4 table-specialization decision against production Rust FIR.
Unlike the C++ instruction hierarchy, canonical FIR already owns concrete
array element types and lengths at the Cmajor boundary, so read-only,
writable, waveform, and generated tables can be emitted directly without a
name-indexed `CmajorTablePlan`. Module Rustdoc and the porting plan document
this representation-level `adapted` mapping and why no detached side table is
introduced.

Structural tests cover runtime stores and dynamic `.at` access, waveform
initializers, generated tables at two sizes, and repeat compilation in one
process to detect leaked specialization state. All table fixtures are
self-contained and use the production signal-to-FIR lane.

Validation: eleven Cmajor integration tests; read-only, writable, waveform,
and generated-table sources accepted by Cmajor 1.0.3175 with
`generate --target=syntaxtree`; deterministic repeated emission confirmed.

## Add the scalar Cmajor emitter core

Commit date: 2026-08-04

Source commit: this commit

Replaced the Cmajor scaffold with a typed FIR-to-Cmajor source emitter. The
first slice emits scalar streams, processor fields, single/double-aware types
and literals, scalar expressions and control flow, delay-array access, math
mapping, helper functions, separated `control`, and the forever-running

bring-up instead of a scaffold.

## Plan the scalar Cmajor backend port

Commit date: 2026-08-04

Source commit: this commit

Added the Cmajor backend port and test plan against the pinned C++ Faust
reference `8eebea429`. The plan inventories the source container, instruction
visitor, UI/event contract, table specialization, architecture wrappers,
application tooling, and upstream impulse path. It freezes scalar
`-lang cmajor` with single/double precision as the first completion target and
defers polyphonic, `cmajor-dsp`, hybrid, and SDK tooling to separately gated

The lifecycle mapping is explicitly `adapted`: Cmajor tables remain processor

`classInit -> instanceInit` and direct `instanceInit` does not call
`classInit`. The test plan layers pure Rust structural and numeric checks,
pinned C++ differential output, current Cmajor frontend validation, generated
C++ impulse execution, and `-O0`/`-O4` parity.

`generate --target=syntaxtree`; Markdown whitespace and diff check. The pinned
