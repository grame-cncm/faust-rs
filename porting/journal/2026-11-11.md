# 2026-11-11

## Release 0.9.6

Commit date: 2026-11-11

Source commit: this commit

Raised the workspace package version from 0.9.5 to 0.9.6, 60 commits after
0.9.5. Among them: the Mojo backend (`-lang mojo`, from grame-cncm/faust#1293)
with its GPU batch contract (per-voice state as a structure of arrays, state in
locals, the GPU examples and their measurements); large methods outlined into
methods of their own (`fir::outline`, on by default for Mojo, `--outline` for
C++) and large Mojo tables packed; one generated table per content across clock
domains; `-json` as a companion of the generated code and `-O`; `fad` of a
block-mode `rad`; and the diagnostics campaign. All member crates inherit the
version through `version.workspace = true`.

Updated the 72 snapshots that embed the version string (70 under
`tests/cli-transcripts`, faustprobe's `cli_version.txt` and
`compile_error_json.txt`) by replacing the version text rather than
re-recording, so that uncommitted work in the tree could not reach them; each
differs from its committed text by the version string alone. The string keeps
its length, so the wasm data offsets of those snapshots are unchanged.
