## fir: `--outline` promotes locals only passed to outlined methods to struct fields

Commit date: 2026-11-10

Source commit: this commit

Study `porting/cpp-isomorphic-outlined-functions-study-2026-11-10-en.md`:
the 1,296 methods `--outline` writes for the 36 × 36 gated-delay program
are identical up to renaming, but sharing their body is not where the C++
build time goes. `compute` still carries 23,328 block-rate locals
(`fSlowOD*`, `iSlowODDone*`) across the sample loop, each passed by address.
Prototypes measured by rewriting the output: one shared function with field
pointers (rejected: 2.8 times slower to run), locals as fields (B: 31 s,
28 % faster), an array of line instances with a loop (C: 21 s, slower with
sparse gates; not started). In FIR `FirStore` gives the same id to the
canonical bodies (fields through the instance, locals and parameters
renamed by first use), so detecting isomorphic functions would be an id
comparison.

B implemented in `fir::outline` (user decision: in FIR), plan
`porting/fir-outline-reference-promotion-plan-2026-11-10-en.md`:

- `OutlinePolicy::promote_references` (on for the C++ CLI, off for Mojo),
  `OutlineReport::promoted`;
- producer `outline/promote.rs`: a scalar local declared at the top of a
  method with an initializer, passed by reference to functions outlined
  from it, used nowhere else and declared once in the module, becomes a
  struct field; the declaration becomes a store at the same place, the
  address arguments and reference parameters go, nested outlined functions
  included;
- independent checker `outline/promote_check.rs` (sections, signatures,
  declarations, demotion back to the source by id); mutations
  `PromoteKeepDeclaration`, `PromoteDropReset`, `PromoteSwapFields`.

The first versions were quadratic (declaration counts as a memoized map per
node over FIR's list-shaped blocks; one walk of `compute` per candidate) and
timed out at N = 36; now one walk each, 1.2 s (`porting/MEMOIZATION.md`
2.32).

Measured, N = 36: clang 66 s → 34 s, runtime 8.7 → 6.4 ms per 256-frame
block with all gates, 0.205 → 0.154 ms with one in 36; outputs bit-identical
to `--outline` before. Registry: DIFF-CLI-018 updated.

## codegen: `--outline` for C++, large methods split into methods of their own

Commit date: 2026-11-10

Source commit: this commit

A user program, a 36 × 36 matrix of gated delay lines (each line
`(gate, _) : ondemand(delay : gain : fi.highpass(8))`), built in minutes:
faust-rs wrote the C++ in 9 s, then clang spent the rest on one 190,000-line
`compute` (all 1,296 lines in one sample loop). Measured on reduced
matrices, clang `-O3` time grows as the square of the function's size
(N = 6, 12, 18: 1.0 s, 10.5 s, 54 s); `-O1` and `-vec` do not help.

`fir::outline`, written for Mojo on 2026-11-09, is now available to the C++
backend (plan `porting/cpp-outlining-plan-2026-11-10-en.md`):

- `CppOptions::outline` and the CLI option `--outline` (C++ only, off by
  default). An outlined function is a method `<method>Outline<k>` of the
  class, called on `this` under the block's `if`; a local the block stores
  into is passed as `T* RESTRICT` by address (from the pass's report), a
  channel pointer by value without `RESTRICT` (a host may process in place).
- The pass keeps a module's sub-modules (the C++ table classes) instead of
  refusing the module; `OutlineError::SubModules` is gone.
- `OutlinePolicy::pointer_params` (off for Mojo, on for C++): a free local
  pointer of a scalar, never stored into, addressed, tee'd or shifted, is
  passed by value — every `ondemand` block of the program reads
  `input0[i0]`, which the pass refused. Checker: rule 3 tells such a
  parameter from a reference by its argument (`LoadVar` of a pointer, not
  an address), rule 4 allows it loads and table accesses at any index, rule
  6 restores their access type. New mutations `PointerAsReference`,
  `PointerStore`, both rejected by rule 4.

Measured, N = 36, Apple clang `-O3 -ffast-math`: 66 s with `--outline`,
1,690 s (28 min) without it, wall clock on a partly busy machine
(1,298 methods; faust-rs 10.1 s instead of 8.9 s). N = 12: 10.5 s → 7.0 s;
N = 18: 54 s → 9.0 s.

Validation: `crates/compiler/tests/cpp_outline.rs` (shape; 288 hermetic
corpus/impulse programs emit C++ under an every-block and an every-run
policy, 223 changed; the 48 changed impulse programs compute bit-identical
outputs to their plain build, three classes in one translation unit built
with `tests/impulse-tests/archs/faust_minimal.h`); outline unit tests (6
new); codegen identity of `-lang cpp` (without `--outline`) and
`-lang mojo` over the `.dsp` of `tests/` and `examples/` against the base
commit.

Also measured for the same program: `-dlt 1024` stores the delay lines at
their exact size (96,001 floats instead of 131,072), 498 MB of buffers
instead of 679 MB, at no compile-time cost.

Registry: DIFF-CLI-018. Not done: the C backend, a CLI knob for the budget.

## cli: `-json` is a companion of the generated code, as in C++; `-O` ported

Commit date: 2026-11-10

Source commit: this commit

With `/usr/local/bin/faust` pointing to faust-rs, `faust2max6 clarinetMIDI.dsp`
failed with `--architecture is currently supported only for
C/C++/Cmajor/Julia/Mojo output`. The script runs
`faust -i -cn clarinetMIDI -json -a max-msp/max-msp64.cpp clarinetMIDI.dsp -o
$TMP/clarinetMIDI.cpp` and builds the patcher from `clarinetMIDI.dsp.json`.
In C++ `-json` only adds a file: `CodeContainer::generateJSONFile` writes
`subst("$0.json", makeDrawPath())` for every backend and the code goes out as
usual. faust-rs read `-json` without `-lang` as a JSON-only mode (JSON on
stdout, `-a` refused), and `-json -lang X` wrote `<-o stem>.json` and
required `-o`. The difference was not in the registry.

Now (user decision: full C++ parity):

- `--json` no longer counts as a mode in source mode (`cli/validate.rs`):
  without `-lang` the default C++ backend runs, wrapped under `-a`, and every
  backend writes the companion at `runner::json_companion_path`: the input as
  given plus `.json`, or `<-O dir>/<name>.dsp.json`. `-o` is no longer needed.
  WASM keeps its `-o` `.json` helper (C++ `createHelperFile`) and adds the
  companion.
- `-O/--output-dir` is ported for the `-o` file and the companion
  (`runner::resolve_output_dir`: canonicalized, `ERROR : invalid directory
  path` as C++). It does not move `-svg` output.
- `--json` with a Rust-only mode that emits no code (`--check`, `--parse`,
  `--dump-sig*`, ...) is rejected with a message instead of the usage text.
- `--fir-fixture` keeps its standalone JSON and `-o`-named companion: it is
  Rust-only and has no DSP input.
- Callers updated: the cmajor CLI test, `tests/impulse-tests/tools/impulseasc.js`
  (passes `-O tmpDir` so no `.dsp.json` lands in the corpus), README.

Registry: DIFF-CLI-017. Tests: `crates/compiler/tests/cli_json_companion.rs`
(`-json -a` wrapping and companion, `-json` alone, `-lang c -json` without
`-o`, `-O`, WASM helper plus companion, invalid `-O`, `--check --json`
rejected) and `json_companion_path_follows_cpp_make_draw_path`. Checked by
hand: `faust2max6 clarinetMIDI.dsp` with this binary first on `PATH` builds
`clarinetMIDI~.mxo`, `clarinetMIDI.maxpat` and `ui.js`; `impulseasc.js` on
`APF.dsp` renders as before.

## transform: a generated table with a stateful generator is shared across clock domains too

Commit date: 2026-11-10

Source commit: this commit

A check of the unpushed commits of `main-dev` found that `DIFF-BEH-029`
(`0d7e4a9b`, one generated table per content) did less than its message, the
registry and `MEMOIZATION.md` §2.30 said. They named "the stateful primitives
of any table generator" among the cases covered; the tests only used
`waveform`. `os.osc` read in two `ondemand` bodies and at the top level still
gave three `mydspSIG` classes and three tables.

Cause: the prepared forest is in symbolic form, where each recursion group has
a variable of its own. The domain copies of a generator with state are as many
groups, so the `ba.time` of the oscillator table is `SYMREC(W1, …)` in one
body and `SYMREC(W2, …)` in the next (`--dump-sig-dag-prepared`). Once the
clock annotations were dropped the two copies still differed by that name, and
`TableContentKeys` kept them apart. Nothing wrong was emitted: the sharing was
missed, for the most common table there is.

Fix, in `crates/transform/src/signal_fir/table_content.rs`: the key is now the
declocked generator with the recursion variables it binds renamed `rec#0`,
`rec#1`, ... in order of first visit (`canonical_recursions`). A generator is
compiled from a clone of its payload alone, so such a name cannot reach the
table. The renaming is injective and leaves a reference to a group bound
outside the generator under its own name: two such references name two
different signals. A generator without a binder (a waveform) is its own
canonical form, found by a test memoized across tables, so the coopiano tables
are not walked again.

Outcome:

- `os.osc` in two `ondemand` bodies and at the top level: 3 sub-modules and
  tables → 1.
- Base-vs-new differential over the 646 `.dsp` of `tests/` and `examples/`,
  C++ scalar, `-double` and `-vec` (`ondemand_stft_denoiser_1024` left out of
  `-vec`, as before): eight programs differ, all in `tests/impulse-tests/dsp`
  (`ondemand_05_nested_voices`, `07_nested_sum_select`, `08_nested_par_select`,
  `10_adsr_layers`, `15_branch_filters`, `16_lfo_modulation`,
  `17_parallel_matrix`, `18_toggle_morph`): 2 or 3 sub-modules each became 1,
  the C++ 4 to 18 % smaller. Every other output is identical; 38 error
  fixtures fail on both sides.
- Those eight against the C++ reference, impulse lanes `interp`,
  `interp-vec0`, `cpp`, `cpp-vec0`, `c`, `cranelift`, `rust`, `wasm`: 8/8 on
  each.
- Compile time, the ten compile-budget programs, scalar and `-vec`, best of
  nine against the build before: ratios 0.98 to 1.04 (hand-timed; the gate does
  not measure on this Mac).

Tests: six unit tests in `table_content.rs` (groups differing by variable and
domain share an owner; different contents, two groups in another order, and
references to two outer groups stay apart; a group inside a group; a waveform
untouched) and three tests in `crates/compiler/tests/ondemand_table_sharing.rs`
(a stateful generator read from three domains is one sub-module on six text
backends and one table under `--table-init const`; two stateful generators of
different content stay two; the three domains' reads checked sample by sample
in the interpreter, scalar and `-vec`, `opt_level` 0 and max). With the
renaming switched off, four of the unit tests and the structural integration
test fail.

Registry `DIFF-BEH-029` corrected, `MEMOIZATION.md` §2.30 re-keyed.

Seen on the way, not changed: `make build` in `tests/impulse-tests` runs
`cargo build --release -p compiler --bin faust-rs -p impulse-runner`, and the
`--bin faust-rs` filter keeps `impulse-runner` from being built in a fresh
checkout.
