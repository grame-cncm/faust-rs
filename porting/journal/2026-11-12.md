# 2026-11-12

## codegen: wasmparser becomes a dev-dependency

Commit date: 2026-11-12

Source commit: this commit

Cargo reported `wasmparser` as an unused dependency of `codegen`
(`cargo::unused_dependencies`). The crate is only used by the wasm backend's
unit tests (`crates/codegen/src/backends/wasm/tests.rs`), to decode and
validate the emitted modules; the library code emits through `wasm-encoder`
alone. Moved it from an optional dependency enabled by `backend-wasm` to
`[dev-dependencies]`, and dropped `dep:wasmparser` from that feature. No change
to generated code or to `Cargo.lock`.

Known gap, unchanged by this commit: `cargo check -p codegen
--no-default-features` fails, because `backends/wasm/mod.rs` imports
`wasm_encoder` without being gated on `backend-wasm`. CI never builds without
default features.
