# 2026-08-02

## Normalize Julia single-precision libm names

Commit date: 2026-08-02

Source commit: this commit

The Julia backend now converts C-style `f32` libm names emitted by
`maths.lib` into Julia's precision-generic functions. This covers the standard
math family, the six hyperbolic functions, and `isnan`/`isinf`/`copysign`.
`fminf` and `fmaxf` continue to use the existing NaN-absorbing Faust helpers.

Validation: Julia `f32` source generation for `math.dsp`, Julia parser/runtime
check, and the codegen crate tests.
