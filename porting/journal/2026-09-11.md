# 2026-09-11

## MEMOIZATION.md swept against the code since June

Commit date: 2026-09-11

Source commit: this commit

The roadmap's last content change was 2026-08-08, and it had drifted in both
directions: entries describing state that no longer exists, and eleven
memoization sites added since 2026-06-22 that it never mentioned. Every commit
in that range was read; what the sweep found is now in `porting/MEMOIZATION.md`.

**New entries.** Parser: the remote import cache (§2.1b), whose payload is the
final URL after redirects so that a redirect target cannot slip past the
duplicate and cycle detection, and the two process-wide `OnceLock`s holding the
lexer definition and the combined DFAs (§2.1c). Eval: the normal-form fast path
(§2.4c) and closure interning (§2.4d). Normalize: the table promotion cache and
its `None` sentinel, which is the identity value doubling as the `Rec` cycle
marker exactly as in §2.9 (§2.9b). Transform: CSE per execution scope (§2.12b),
straight-line scalar table-load reuse (§2.12c), FIR state keyed by clock
occurrence (§2.12d), the delay planner's dominance memo (§2.12e), the
block-reverse-AD tapes and the forward-output keys (§2.19), the clock
inference sweep (§2.20), and `Special`'s sequence summaries (§2.21). Propagate:
the canonical slot and UI identities (§2.16), the forward-AD memos (§2.17) and
the stateful-RAD linearity classifier (§2.18).

**Corrections.** §2.11 described `node_types` / `group_types` / `active_groups`,
deleted on 2026-03-19; the typing memo is now the annotator's own table, and the
fact worth recording is that the staging map is rebuilt wholesale at each of the
five schedule points, because every rewrite invalidates it. §2.12's flat
lowering cache is a scope stack since 2026-07-15. §2.15 still stated the
slot-environment restriction that 2026-08-30 removed, along with the
measurements of its removal.
§2.6's arity cache now lives on `BoxCompileOutput` and crosses a public API
boundary. Stale paths fixed in §2.2, §2.5, §2.7, §2.8, §2.10, §2.13.

**Two rules added.** Rule 6: the key names everything the value depends on — a
`SigId` means one thing inside a clock domain and another in its sibling, one
thing inside a recursion binder and another outside, one class at one de
Bruijn level and another at the next. Three separate bugs, all silently wrong
rather than slow. Rule 7: count the cost of the key itself, after a key computed
by a dump that prints a shared graph as a tree spent five minutes and ten
gigabytes before a single instruction was lowered.

**What the sweep says about the roadmap.** Of the seven changes that moved
compile time since 2026-08-06, three are not caches: two are better keys and one
is a better scope. §6 now records that, and the priority list now puts
hash-consed evaluator environments first (§3.7) — the last place where the port
pays a cost C++ does not, and the change that would retire §2.4c's exception
list.

Also noted, in §4 rather than §2: the interpreter FFI factory cache is keyed by
the `.fbc` header's SHA field, and the codegen layer writes an empty string
there, so distinct interpreter factories coalesce on the first insert. Not fixed
here.
