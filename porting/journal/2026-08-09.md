## Batch the compilation-budget calibration

Commit date: 2026-08-09

Source commit: this commit

The Ubuntu compilation-budget gate intermittently rejected a valid run before
measuring the basket because the cheap `karplus.dsp` calibration rounded down
to 4 ms against its 5 ms validity floor. Calibration now compiles the cheap
DSP in a timed batch and derives a ceiling-rounded per-run duration from that
window. The configured floor is explicitly reduced from 5 ms to 4 ms; the
batch removes one-millisecond timer quantization while preserving the existing
normalized baselines.
