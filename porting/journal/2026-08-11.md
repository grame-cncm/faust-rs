## Match C++ C-family source identity metadata

Commit date: 2026-08-11
Source commit: this implementation commit

- Added explicit `metadata_name` and `metadata_filename` carriers to the public
  C and C++ backend option structs. This is an `adapted` API mapping: Rust keeps
  source identity explicit instead of reading C++ process-global state.
- The compiler facade now derives the callback filename from the source basename
  and the callback/banner name from top-level `declare name`, falling back to
  the source stem. Backend class-name overrides remain independent.
- Added C and C++ regression coverage for declared/default names, basename-only
  filenames, and a custom generated class name.
- Closed and removed `DIFF-GAP-012`; non-identity metadata transport remains
  tracked independently as `DIFF-GAP-013`.
