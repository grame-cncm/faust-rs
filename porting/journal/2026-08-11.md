## Add the optional native HTTP(S) transport

Commit date: 2026-08-11
Source commit: this implementation commit

- Added the default-off `network-imports` feature and a native-only
  `UreqSourceFetcher`; ordinary and `wasm32-unknown-unknown` builds do not link
  the HTTP/TLS stack.

  redirect handling, three-hop/default timeouts, explicit body bounds, strict
  UTF-8 conversion, and stable transport-independent error categories.

  redirect target are re-authorized; URL credentials are rejected and redacted,
  while trusted native CLI hosts can explicitly install `AllowAllRemoteUrls`.
- Added hermetic loopback tests for success, relative redirects, redirect
  ceilings, target-policy rejection, HTTP status, oversized bodies, invalid
  UTF-8, and credential rejection.
