## Fix constant-case evaluation and waveform scheduling parity

Commit date: 2026-08-11
Source commit: this implementation commit

- Fixed additive normalization to subtract the numeric negative bucket with
  the same `subNums` rule as Faust C++, avoiding a residual `-1 * 0` that
  prevented computed `case` arguments from matching.
- Aligned waveform and table typing with `sigtyperules.cpp`: waveforms are
  sample-rate scalar values, read-table results inherit the table aggregate
  qualifiers plus their index, and writable tables inherit their write rate.
  The Rust signal builder's direct `rdtbl(waveform, index)` form remains
  supported explicitly.
- Added normalization, evaluator, sigtype, FIR-placement, and vector-plan
  regressions. The external `granulator.dsp` now generates C++ successfully in
  8.55 seconds, and a clean 94-case C++ impulse run matches the Faust C++
  oracle.
- Validated formatting, workspace Clippy/tests, Rust goldens, and the release
  compilation-cost gate without changing its baseline. The first budget run
  had one non-reproducible `cubic_distortion` vector sample 1.6% above its
  ceiling; the immediate full rerun passed.

## Support prefetched remote graphs in browser-WASM

Commit date: 2026-08-11
Source commit: this implementation commit

- Added parser-core `PrefetchedRemoteSourceBundle` and
  `RemoteSourceCapability`: canonical HTTP(S) identities, fragment
  normalization, duplicate rejection, per-source byte bounds, deterministic
  missing-entry errors, and no transport dependency or I/O.
- Extended source-string compilation so a supplied HTTP(S)-named root becomes
  the base of relative imports without being fetched twice; ordinary in-memory
  roots can likewise resolve explicit prefetched URL imports.
- Added repeated `--remote-source <url> <base64>` decoding to the existing
  `wasm-ffi` argument ABI. Payloads require strict base64 and UTF-8, are elided
  from diagnostic option metadata, and install even an empty bundle so missing
  children report their canonical URL.
- Documented the browser/worker prefetch contract across RustDoc, crate/user
  READMEs, the supported subset, and the C++ comparison. The host retains
  asynchronous fetch, redirects, authorization, CORS, and aggregate-size
  policy; the WASM module retains synchronous deterministic compilation.
- Validated parser and `wasm-ffi` unit/integration coverage, workspace Clippy
  and tests, RustDoc, Rust goldens, `wasm32-unknown-unknown` checking, and the
  real debug `libfaust-rs.wasm` export build.
- Ran the release compilation-cost gate repeatedly without changing its
  baseline. Under concurrent desktop CPU load it remained noisy rather than
  case-reproducible: the isolated over-ceiling result moved among
  `reverb_designer`, `spectral_level`, `cubic_distortion`, and the 9 ms APF
  vector measurement, while every front-end case stayed below its ceiling.
  The new branch is inactive for those ordinary no-fetcher compilations; this
  environmental validation exception is recorded instead of ratifying it with
  `--update`.
