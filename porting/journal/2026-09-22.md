## Allow measured timer noise in the compilation-cost codegen gate

Commit date: 2026-09-22

Source commit: this commit

The checked-vector CI job in run 35652142959 failed the normalized codegen
budget for `karplus` scalar: 10 ms versus a 5 ms baseline, with a 6 ms
front-end calibration. The immediately preceding successful run 35651988346,
on a documentation-only predecessor commit, measured 5 ms with the same
calibration. The larger codegen cases stayed close to their baselines, and a
local release run measured 5 ms. This is timing noise in a very short case,
not evidence of a compiler regression.

The normalized codegen ceiling now includes a 5 ms absolute timer allowance
in addition to its configured percentage tolerance. Large cases still have
effectively the same limit. A focused test covers the CI measurements and
checks that a larger increase still fails. The versioned baseline is unchanged.

Validated with `cargo fmt --all`, `cargo clippy --workspace --all-targets --
-D warnings`, `cargo test --workspace --all-targets`, all five structure gates,
and the release `compile-budget-check`. The workspace test suite needed its
local HTTP fixture to bind a loopback port, so it was run outside the sandbox.

## optimizers.lib 0.10.0: the bus loops take a rate, a range and a start per parameter

Commit date: 2026-09-22

Source commit: this commit

The six bus loops of `optimizers.lib` (`lsq_N`, `lsq_N_rad`, `descend_N`,
`descend_N_rad`, `descend_N_clocked`, `descend_N_rad_clocked`) took one
engine, one pair of bounds and one start for their `N` parameters, so that a
descent on parameters of different scales and units, the knobs of an
amplifier, had to go through the fixed-arity loops (`descend_3D_clocked`,
five at most) or through a unit-cube reparametrisation, as the faust-diff
projects did. The occasion was the question of a generic adaptive operator:
widget modulation already rebinds any program's sliders to learned signals
(`["gain": (!, _), "bias": (!, _) -> e]`, one modulator per target, the same
in the C++ compiler), and what stopped a program's own ranges from being
used as the descent's bounds was this signature.

`upd`, `lo`, `hi` and `init` now accept either a scalar (an engine), the
same for every parameter, or a list of `N`, one per parameter, through an
internal `_nth(i, x)` that takes the `i`-th entry of a list and returns a
scalar unchanged (pattern matching on the parallel composition). The six
bodies index their arguments with it; the documentation says so in each
`Where`, and `descend_N_clocked` gains an example with three knobs in their
own units. Version 0.9.0 to 0.10.0, the overviews updated.

Two fixtures: `opt_descend_n_clocked_lists.dsp` learns a gain in [0, 2], an
offset in [-100, 100] and a slope in [-5, 5] with an Adam rate each, where
one rate would leave the offset behind; `opt_bus_scalar_vs_lists.dsp`
outputs the residuals of `descend_N` and `descend_N_clocked` in scalar form
and in list form with equal entries, and the test asks that each pair be
identical to the bit, so the change of signature moves no existing program.
Checked on faust-diff-ampmodeler too: its online learner rewritten from
`descend_3D_clocked` to `descend_N_clocked(3, …, (adam(0.01), adam(0.02),
adam(0.5)), (0.01, 0, -60), (1, 1, 0), (0.5, 0.5, -10), reset)` renders the
same five outputs over 20 s, identical.

Validated with `cargo fmt --all`, `cargo clippy --workspace --all-targets --
-D warnings`, `cargo test -p compiler --test optimizers_lib` (34 tests) and
the five structure gates.

## Analysis: control inputs as boxes and a wildcard modulation target

Commit date: 2026-09-22

Source commit: this commit

`porting/control-inputs-and-wildcard-modulation-analysis-2026-09-22-en.md`
specifies, without implementing, `cinputs(e)`, `cinput(i, e)`,
`coutputs(e)`, `coutput(i, e)` after `inputs`/`outputs`, and the modulation
target `"*"` with one slot per matched widget in UI order, so that
`optimizers.lib` can offer `adaptive_fad` and `adaptive_rad` on any program. It records what was measured on the way: widget modulation
rebinds sliders exactly (1e-13 against the hand-written library on 24 `fad`
lanes), a label attaches its modulator to itself only (`"a", "b": m` leaves
`a` on the default `*`, in C++ too), a label that matches several widgets
gives them one shared slot, and `"*"` matches nothing today in either
compiler.
