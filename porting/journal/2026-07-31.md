# 2026-07-31

## Clarify Rust execution-option methods in generated output

Commit date: 2026-07-31

Source commit: this commit

Rust output now places a short comment immediately before `impl FaustDsp for
mydsp` only when `-ec` and/or `-os` produce `control()` or `frame()`. It
explains that the trait deliberately retains the legacy block `compute`
contract, while those options expose `control()` and `frame()` as public
inherent methods. The execution-options integration test asserts both the
generated comment and its absence from classic output.

Validation: `cargo fmt --all`; targeted execution-options test; workspace
clippy; workspace tests.

## Repair Rustdoc links and document public ABI helpers

Commit date: 2026-07-31

Source commit: this commit

A workspace-wide Rustdoc build exposed invalid or ambiguous intradoc links in
the draw and xtask crates and HTML-like option placeholders in the interpreter
FFI. The affected documentation now links only to public Rust items or uses
plain prose for internal implementation details. The public scalar foreign-call
bridge, shared FFI callback-table fields, and interval accessors now document
their ABI and semantic contracts. The interpreter FBC opcode table,
instruction branch targets, serialization failures, and FBC-to-C++
control-flow lowering now also explain the ABI and stack invariants that keep
the pipeline aligned.

Validation: `RUSTDOCFLAGS='-D warnings' cargo doc --workspace --no-deps` and
focused clippy across the documented crates.

## Omit empty FBC-to-C++ else branches

Commit date: 2026-07-31

Source commit: this commit

The FBC-to-C++ generator previously emitted `else {}` when an `If` false
branch contained only `Return`. It now renders branches independently and
omits an empty branch; when only the false branch has statements, it emits the
equivalent inverted condition.

Validation: `cargo fmt --all`; `cargo test -p codegen fbc_to_cpp::tests`;
`cargo clippy -p codegen --all-targets -- -D warnings`; and
`--dump-cpp-from-fbc tests/corpus/FOO.fbc` with no emitted `} else {`.
